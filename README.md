# User Management System

A full-stack User Management System built using the MERN stack.  
This application provides secure authentication using JWT and allows admins to manage users while users can manage their personal profile.

---

## 🚀 Features

### Admin
- Admin login authentication
- Add new users
- View all users
- Edit user details
- Delete users

### User
- Secure login using JWT authentication
- Personal profile page
- Update profile information
- Upload profile photo

---

## 🛠 Tech Stack

**Frontend**
- React
- Redux

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Authentication**
- JWT (JSON Web Token)
